## 다음 순서 (2026-10-25 갱신 — 목표: 기존 마피아 게임과 동일하게)
**목표(사용자 지정):** 예전 게임 "포트 헤일 시제품"(`AI-Mafia/backend/app/devtool/static/prototype.html` + `AI-Mafia/content/`)과 같은 게임을 이 엔진으로 만든다.
**동일 판정:** ① AI 없이(`?noai`) 같은 선택으로 자동 진행한 피드 글이 원본 기록과 같다 (원본 기록: 원본 `/prototype?auto&noai`의 피드 글) ② 화면 구성·연출이 나란히 비교해 같다 ③ AI를 켠 기능(즉흥 행동·장면 사이 이야기·NPC 대화·신문 글·선택지 만들기)이 같은 자리에서 같은 역할을 한다.
**나누는 법:** 예전 **게임 내용 데이터**(장면·세계관·역할·소지품·대화·결말·후일담·미디어 목록)는 게임 프로젝트의 `assets/data/`로 옮긴다(같은 게임이므로). 예전 **엔진·화면 코드는 가져오지 않는다** — 재생 규칙은 게임 스크립트로 새로 쓰고, 일반적인 것만 엔진 도구로 만든다.
각 단계의 완료 조건: 엔진에는 일반 도구만 · 게임은 엔진(편집기·`tool.py`)으로만 · 사람이 코드 없이 조정 값을 찾고 바꿀 수 있음(DESIGN 8장) · **모든 선택지는 플레이어가 재미를 느끼려고 고를 수 있는 것(보상이 있음, `../games/port-hale-winter/docs/mafia.md` 설계 규칙)** · 시험 통과 · 문서 갱신.
