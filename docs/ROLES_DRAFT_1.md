스타2 마피아 위키(sc2mafia.fandom.com)는 자동 읽기가 막혀(HTTP 402) 직업 규칙을 직접 확인하지 못했다. 아래 "스타2 쪽 비슷한 직업" 칸은 마피아류 게임에서 널리 쓰이는 능력을 CM이 아는 대로 적은 것이다. 사용자가 기억하는 규칙과 다르면 그쪽을 따른다.
