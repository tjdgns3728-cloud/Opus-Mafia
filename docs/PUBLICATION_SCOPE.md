# 이번 게시 작업의 범위

작성자: GA / Codex, 인계 후 작성. 준비 시작: 2026-11-14T04:51:29.132316+09:00.

사용자가 “다른 AI가 게임에 접근할 수 있게 git에 올려서 주소를 알려 달라”고 명시적으로 승인했다. 위험도 S의 새 갈래·새 경로 추가 작업으로 진행했다. 기존 원격 갈래, 현재 게임 소스, 실행 중인 서버와 방은 바꾸지 않는다.

입력은 현재 블랙 리지의 게임 코드·동봉 엔진·원고 연결 설명이다. 결과는 다른 AI가 읽고 자신의 환경에서 실행할 수 있는 소스와 인계 문서다. 공용 인터넷 게임 서비스를 배포하는 작업은 아니다.

저장소 규칙은 기준 판 `842ce7df504aa0de55fc58632862259dc63e3aec`의 AGENTS.md, ai-ops/PROJECT_CHARTER.md(v1.1), TASK_TEMPLATE.md를 읽고 현재 지시와 대조했다. LEARNING_LOG.md는 Git·토큰·게시 관련 선택 부분만 읽었다. 일부 검색 출력이 잘려 전체를 읽었다고 주장하지 않는다. 토큰 커밋 사건을 참고해 실행 토큰·로그·DB를 처음부터 복사 대상에서 제외한다.

과거의 사용자만 푸시한다는 조항은 이번 명시 게시 지시에 의해 대체된다. 과거 자동 시험·독립 검토 절차는 P의 현재 자율 검증 중단 지시를 우선한다. 새 AI 생성, 자동 게임 플레이, AI 호출, 외부 공개 서비스 배포는 하지 않는다.

게시 전 파일 목록·비밀값 포함 여부를 한 차례 확인하고 커밋 후 원격 새 갈래의 커밋 번호만 확인한다. 이것은 게임 검증이나 재미 평가가 아니다. 실제 게시 결과와 커밋은 P에게 보고한다.

제외: 원본 DB, 크롤링 자료, .token/.play_token, 인증 파일, 실행 로그·방 기록, 캐시·출력물, 개인 제공 background.mp3. 배경음 파일은 실행자가 사용 가능한 파일을 별도로 둔다. AI 설정 파일은 실행 옵션이며 인증 정보를 포함하지 않는다. 저작권 표기는 동봉 엔진의 LICENSE를 유지한다.

토큰 사용량·실제 비용은 제공되지 않아 null. 비교 실행이 없으므로 절감률을 계산하지 않는다. 게시 준비 앞부분 검색·읽기 시간은 따로 계측하지 않았다.
